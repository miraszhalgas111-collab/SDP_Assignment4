
# SDP Assignment 4 - Facade Pattern

## Project
Online Food Delivery System

## Description
Java application demonstrating the Facade Design Pattern.

## Subsystems
1. MenuService - manages food menu.
2. OrderService - manages orders.
3. PaymentService - processes payments.
4. DeliveryService - manages delivery.
5. NotificationService - sends notifications.

## Facade
FoodDeliveryFacade coordinates all five subsystems.

## Client
Main.java communicates only with FoodDeliveryFacade.

## Clean Code Principles
1. Meaningful Names
2. Single Responsibility Principle
3. Encapsulation
4. Separation of Concerns
5. Error Handling

## How to Run
Open the project in IntelliJ IDEA and run Main.java.
